# codealpha-simple-E-commerce-store

## Objective

The objective of this system is to provide a simple, user-friendly **E-Commerce Store** web application that allows:

- **Customers** to browse a catalogue of products, view product details, add items to a shopping cart, and complete purchases through a straightforward checkout process.
- **Store administrators** to manage the product inventory (add, update, and remove products) and keep track of customer orders.

### Key Goals

1. **Product Browsing** – Display a list of available products with names, images, descriptions, and prices so customers can easily explore what is on offer.
2. **Shopping Cart** – Allow customers to add or remove products, adjust quantities, and view a running total before placing an order.
3. **Order Placement** – Provide a simple checkout flow where customers can review their cart and submit an order.
4. **Inventory Management** – Enable administrators to maintain an up-to-date product catalogue.
5. **Responsive Design** – Ensure the store is accessible and easy to use across desktop and mobile devices.

This project was built as part of a **CodeAlpha** internship task to practise front-end web development skills using HTML, CSS, and JavaScript.
